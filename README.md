# Portable Cooling Device

Portable wearable cooling device concept designed for thermal comfort,
lightweight portability, and modular assembly.

## Overview
This project explores the development of a neck-mounted cooling device
using compact fans, battery power, and ergonomic housing concepts.

## Features
- Dual fan airflow concept
- Portable battery-powered operation
- Modular housing design
- Lightweight wearable architecture

## CAD Components
- Housing assemblies
- Fan components
- Battery integration
- PCB integration
- USB-C interface

## Tools Used
- SolidWorks
- 3D CAD Modeling
- Mechanical Design Principles

## Current Status
Early CAD prototype development and component integration.
